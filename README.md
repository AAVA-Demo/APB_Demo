# Credit Card Analysis Dashboard - Test Automation

## Project Overview
This repository contains the automated test suite for the Credit Card Analysis Dashboard application.

## Product Requirements
**Build a modern, responsive Credit Card Analysis Dashboard** that enables users to monitor multiple credit cards, spending, transactions, and financial insights from a single interface.

## Business Objectives
- Provide a consolidated view of all credit cards
- Improve visibility into monthly spending and outstanding balances
- Identify category-wise spending patterns

## Target Users
Credit card users managing one or multiple credit cards.

## Core Features
**Must Have:** Dashboard KPIs, Multiple Credit Cards
**Should Have:** Monthly Spend Trends, Card-wise Spend Analysis

### Dashboard KPIs
- Monthly Spend
- Total Credit Limit
- Available Credit
- Outstanding Amount

### Analytics
Provide interactive visualizations for:
- Category-wise Spending
- Categories: Food & Dining, Fuel, Shopping, Travel, Entertainment, Utilities, Healthcare, Education, and Miscellaneous

## Scope
**In Scope:** Dashboard, Cards, Transactions
**Out of Scope:** Real Bank Integration, Card Payments, Fund Transfers, Loans, and Payment Gateway Integration

## Acceptance Highlights
Users can successfully view multiple cards, monthly spending, credit limits, available credit, outstanding balances, and responsive layouts.

## Test Automation Framework
- **Framework:** Playwright (JavaScript)
- **Pattern:** Page Object Model (POM)
- **Test Cases:** 27 test cases covering 6 user stories
- **Coverage:** Dashboard KPIs, Transaction Management, Analytics, Multi-card Overview
